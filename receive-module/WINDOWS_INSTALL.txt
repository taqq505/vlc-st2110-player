ST2110 SDP Loader for VLC (Windows) - インストール手順
======================================================

このフォルダには次の2つが入っています。
  - libst2110_plugin.dll   ... ST2110-20 (10bit) 受信用 VLC プラグイン本体
  - st2110_sdp_loader.lua  ... SDP貼り付けUI (VLC Lua拡張)

1. libst2110_plugin.dll を配置する
   -----------------------------------
   下記のいずれかに置いてください（両方入れる必要はありません）。

   a) VLC本体のプラグインフォルダ（管理者権限が必要な場合あり）
        %ProgramFiles%\VideoLAN\VLC\plugins\access\

   b) ユーザー単位のプラグインフォルダ（無ければ作成）
        %APPDATA%\vlc\plugins\access\

2. st2110_sdp_loader.lua を配置する
   -----------------------------------
        %APPDATA%\vlc\lua\extensions\
   （無ければ作成してください）

3. VLC を再起動する
   -----------------------------------
   起動時にプラグインキャッシュが再生成されます。

4. 拡張を有効化する
   -----------------------------------
   VLCメニュー「表示」→「プラグインと拡張機能」から
   "ST2110 SDP Loader" を有効化すると、SDP貼り付け用の
   ダイアログが開きます。

5. （任意）10bit映像を libst2110_plugin.dll 経由で受信する
   -----------------------------------
   st2110_sdp_loader.lua をテキストエディタで開き、先頭付近の

        local USE_CUSTOM_VIDEO = false

   を

        local USE_CUSTOM_VIDEO = true

   に書き換えて再配置してください。false のままだと映像はVLC内蔵の
   RTP経路（10bitパッキングは解けません）に渡り、音声のみが実質的に
   再生対象になります。true にすると映像は libst2110_plugin.dll
   （st2110://）経由になり、音声は引き続きVLC内蔵経路（input-slave）
   で再生されます。

注意
-----------------------------------
libst2110_plugin.dll は GitHub Actions 上の未検証ビルドです。
まず「表示」→「メッセージ」（またはvlc -vvv起動）でエラーが出ていないか、
vlc --list に "ST2110" が出るかを確認してください。
